# Site institucional - Randaza Engenharia

Protótipo avançado do site institucional da Randaza, criado como projeto independente do ERP.

## Conteúdo incluído

- Homepage responsiva e acessível
- Serviços e áreas de atuação
- Projetos com registros reais do portfólio
- Comparador interativo de fachada antes/depois
- Método de trabalho
- Transparência, diário de obra e sistema próprio
- História e credenciais da direção técnica
- Contatos e botão direto para WhatsApp
- Metadados sociais e configuração inicial para Railway

## Executar localmente

Requer Node.js 22.13 ou superior e pnpm.

```bash
pnpm install
pnpm dev
```

Abra `http://localhost:3000`.

## Publicar

Envie o conteúdo desta pasta para o repositório separado do site. No Railway, crie um novo projeto a partir desse repositório. O arquivo `railway.toml` contém os comandos de construção e inicialização.

Não coloque este projeto dentro do repositório do ERP em produção.
